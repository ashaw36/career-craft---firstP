## 十二条 UI 主旅程

1. 首次启动 → 导入/录入经历 → 创建角色。
2. 编辑/删除/冲突经历并验证原文保留。
3. 角色切换 → Fit 差异 → 人工覆盖/重置。
4. 5 模板简历 → Markdown/PDF 导出。
5. 简历调优 → 确认 → 撤销/恢复 → 版本比较。
6. 中英文 JD → 匹配 → Gap → 投递状态。
7. 经历重述 → 编辑 → 重置 → 重生成。
8. 技能搜索/详情/自定义 → 假设分析。
9. 学习路径 → 进度 → 完成转经历 → 外链受控。
10. Provider CRUD → Key 不回显 → fallback → 测试连接。
11. URL 采集成功/失败/登录/手动粘贴降级。
12. 断网重启、崩溃恢复、数据库升级与备份恢复。

## 性能门槛

- Rust 核心行覆盖 ≥85%，迁移/安全/序列化关键分支 100%。
- 前端行覆盖 ≥80%，十二条 E2E 全通。
- 安装器目标 ≤35MB（Evergreen WebView2，不含离线 runtime）。
- 冷启动 ≤2s，空闲内存 ≤180MB。
- 1000 经历查询 ≤500ms；UI 本地操作 ≤500ms。
- JD 匹配 ≤10s、简历生成 ≤30s（网络条件固定）。

## 发布阻断条件

- 任一 BMAD P0/P1 或已交付 Sprint 11–13 行为缺失。
- 任一本次纳入的 P2/未完成需求未实现或无测试。
- 旧库无法无损升级或无法恢复。
- API Key 明文、日志泄密、远程脚本或越权 command。
- PDF 中文乱码/截断，DOCX/PDF 黄金样本失败。
- 干净 Win10/11 无法一次安装启动、升级丢数据或无回滚。
