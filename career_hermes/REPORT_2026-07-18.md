## 二、新功能开发

### 2.1 批量导入 — LLM 文件分析

**新增文件:**
- `src/llm/prompts/file_analysis.py` — 专门的文件分析 Prompt，支持从项目文件/汇报/总结中自动提取结构化经历

**修改文件:**
- `src/services/import_parser.py` — 新增 `analyze_file_with_llm()` 方法

**使用方式:**
```python
parser = ImportParser()
drafts = await parser.analyze_file_with_llm(file_content, file_type="项目总结")
for draft in drafts:
    await exp_mgr.create_from_draft(draft)
```

**特点:**
- 自动提取时间、公司、职位、成就、技能、metrics
- 支持多组经历从单个文件中一次性提取
- 带 JSON 解析容错回退
- 需要在 UI 层集成文件选择对话框（待实现）

## 三、开源简历/岗位匹配调研

### 3.1 值得参考的开源项目

| 项目 | Stars | 核心价值 | 可借鉴点 |
|------|-------|---------|--------|
| [srbhr/Resume-Matcher](https://github.com/srbhr/Resume-Matcher) | 27.8k | AI简历匹配 | **TF-IDF + Cosine Similarity** 计算简历-岗位相似度；技能关键词提取和匹配度计算 |
| [xitanggg/open-resume](https://github.com/xitanggg/open-resume) | 8.7k | 开源简历解析 | 简历结构化解析逻辑；简历与岗位的匹配分析 |
| [OmkarPathak/pyresparser](https://github.com/OmkarPathak/pyresparser) | 959 | 简历信息提取 | 基于spaCy的NER提取技能、公司、职位 |
| [AnasAito/SkillNER](https://github.com/AnasAito/SkillNER) | 214 | 技能NER | 基于规则的技能实体识别，可直接用于岗位描述和简历的技能抽取 |

### 3.2 匹配打分优化方案

**当前问题:**
- 打分过于粗糙：技能60%、经验30%、其他10%
- 缺少语义匹配：简单的关键词包含检查，未考虑词义相似度
- 无技能等级区分："精通Python"和"了解Python"得分相同

**推荐升级路线:**

1. **短期（立即可行）**
   - 技能匹配加入**等级权重**：必夈/精通/熟悉/了解 分别给 1.0/0.8/0.5/0.2
   - 引入**经历时间衰减**：3年内经历权重×1.0，3-5年×0.8，5年以上×0.6

2. **中期（建议 Sprint 9）**
   - 集成 **TF-IDF + Cosine Similarity** 计算简历与岗位描述的文本相似度
   - 引入 **SkillNER** 进行技能实体提取（比关键词包含更准确）

3. **长期（建议 Sprint 10+）**
   - 引入 **Sentence-BERT / BGE** 语义相似度计算，捕捉"数据分析"与"数据科学"等近义词
   - 将 Resume-Matcher 的匹配框架做为参考进行重构
