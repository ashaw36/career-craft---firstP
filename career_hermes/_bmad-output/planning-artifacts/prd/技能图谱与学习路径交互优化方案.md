# 技能图谱与学习路径交互优化方案

> 状态：已确认执行 | 日期：2026-07-19

## 问题诊断

### 问题 1：技能图谱点击体验差
- 点击卡片后只在页面底部展开面板，不是模态弹窗，视觉层级弱
- 前置技能/关联技能是静态标签，不可点击跳转

### 问题 2：学习路径没有可点击链接
- 后端 `learning_recommender.py` 返回数据缺少 `url` 字段
- 前端"访问链接 →"因 `link` 为空无法显示或不可点击
- 用户无法打开具体学习内容

### 问题 3：两页流转断层
- 技能图谱"查看学习资源"只跳转并填入技能名，需再点一次"生成路径"

---

## 优化方案

### 一、技能图谱页（prototype/ui-prototype.html）

#### 1.1 模态弹窗替代底部面板
- 点击技能卡片 → 居中模态弹窗 `#skill-modal`
- 弹窗内容：技能名、分类标签、描述、前置技能（可点击）、关联技能（可点击）、学习资源入口链接
- 弹窗右上角关闭按钮，点击遮罩层也可关闭
- 弹窗内增加「生成学习路径」按钮

#### 1.2 技能标签可点击跳转
- 前置技能标签点击 → 关闭当前弹窗 → 打开该技能的详情弹窗
- 关联技能标签同理

#### 1.3 与技能图谱数据联动
- 从 `skill_graph.json` 读取 `learning_url` 字段，在弹窗内显示"推荐学习入口"

### 二、学习路径页（prototype/ui-prototype.html）

#### 2.1 自动触发路径生成
- URL 参数 `?skill=xxx&auto=1` 时，页面加载后自动填入技能名并调用 `generateLearningPath()`
- 技能图谱弹窗点击「生成学习路径」时，跳转至 `page=learning&skill=xxx&auto=1`

#### 2.2 资源卡片展示可点击链接
- 每个资源卡片显示可点击的链接按钮
- 有真实 `url` 时显示"访问资源 →"
- 无真实 `url` 时降级为搜索链接（Bilibili/知乎/Google 搜索该技能+资源标题）

### 三、后端（src/services/learning_recommender.py）

#### 3.1 模板库补充 url
- 每个模板资源增加 `url` 字段：
  - Kubernetes: https://www.bilibili.com/video/BV1Qv41167ck/
  - Docker: https://docs.docker.com/get-started/
  - gRPC: https://grpc.io/docs/
  - Python: https://docs.python.org/zh-cn/3/tutorial/
  - SQL: https://www.bilibili.com/video/BV1UE41147KC/
  - ML: https://www.coursera.org/learn/machine-learning
  - PM: https://www.sanjieke.cn/

#### 3.2 LLM Prompt 要求返回 url
- 在 prompt 中明确要求每个资源包含 `url` 字段
- 课程类给平台链接，书籍给豆瓣链接，项目给 GitHub 模板链接
- 若 LLM 未返回 url，前端降级为搜索链接

#### 3.3 字段映射
- `api_handler.get_learning_path()` 返回时确保 `url` 字段存在（优先）
- 兼容旧数据的 `link` 字段映射

### 四、数据层（src/data/skill_graph.json）

#### 4.1 高频技能补充 learning_url
- 为 50 个节点中高频技能补充 `learning_url`，指向优质入门资源
- 例：
  - `user_research` → https://www.nngroup.com/articles/ux-research-methods/
  - `requirement_analysis` → https://www.woshipm.com/
  - `python` → https://docs.python.org/zh-cn/3/tutorial/
  - `docker` → https://docs.docker.com/get-started/

### 五、API 层

无需新增 Bridge API，复用现有：
- `getSkillGraph` / `searchSkills` / `getLearningPath`
- 仅需调整返回数据结构
