## 🗺️ 功能路线图

### Phase 1：价值验证（当前 → 2周后）
**目标：证明"我能用它找到更好的工作/拿到更高薪资"**

| 功能 | 优先级 | 用户价值 | 验收标准 |
|------|--------|---------|---------|
| **真实 LLM 接入验证** | P0 | 验证核心链路可用性 | 端到端跑通 1 次完整流程，输出质量可接受 |
| **经历批量导入** | P0 | 解决冷启动，5 分钟完成数据录入 | 支持 Markdown/纯文本/JSON 导入，解析准确率 >70% |
| **PDF 简历导出优化** | P0 | 可直接用于投递 | 排版专业、中文无乱码、信息完整 |
| **岗位匹配精度调优** | P0 | 匹配结果可信 | 高匹配岗位与直觉一致，低匹配有明确 Gap 说明 |
| **Boss 直聘爬虫** | P1 | 自动获取岗位，减少手动粘贴 | 稳定抓取 10+ 岗位，含完整 JD 和薪资 |
| **匹配结果历史追踪** | P1 | 追踪投递进展，形成数据积累 | 可标记"已投递/面试中/已拒绝"，时间线展示 |

### Phase 2：体验打磨（2-4 周后）
**目标：从"能用"到"好用"，打磨核心差异化体验**

| 功能 | 优先级 | 用户价值 | 验收标准 |
|------|--------|---------|---------|
| **简历模板配置系统** | P0 | 满足不同场景审美，一键切换风格 | 见下方「模板配置详细设计」 |
| **多角色切换增强** | P0 | 1 份经历 → N 份定向简历 | 切换角色后简历自动重构，< 3 秒 |
| **Gap 分析可视化** | P0 | 直观看到技能短板 | 雷达图对比"我 vs 岗位要求"，一目了然 |
| **学习路径追踪** | P1 | 不只是推荐，而是跟进学习进度 | 可标记"已完成"，进度百分比展示 |
| **面试准备模式** | P1 | 从简历到面试的延伸价值 | 基于 JD 生成预测面试题 + 回答框架 |
| **数据备份/恢复** | P1 | 防止数据丢失 | 支持导出压缩包 + 导入恢复 |

### Phase 3：能力扩展（远期储备，暂不排期）
**目标：在价值验证通过后，探索产品边界**

| 功能 | 说明 |
|------|------|
| **高级匹配算法** | 更精准的岗位推荐（需大量数据训练） |
| **AI 模拟面试** | 基于 JD 模拟真实面试对话 |
| **行业薪资洞察** | 基于爬取数据的市场行情分析 |
| **社区/模板市场** | 用户共享模板、面试经验 |

> ⚠️ **Phase 3 仅为储备方向，Phase 1-2 未完成前不启动。**

## 📋 简历模板配置系统（详细设计）

### 核心目标
让用户能**一键切换简历风格**，并在切换前**实时预览效果**，同时保留**高级自定义**入口。

### 功能模块

| 模块 | 优先级 | 说明 |
|------|--------|------|
| **模板选择器** | P0 | 下拉选择内置模板：modern / classic / minimal / tech / 外企风格 |
| **实时预览** | P0 | 选择模板后，预览区即时渲染该模板效果（基于当前角色+经历） |
| **主题配置** | P1 | 调整主色调、副色调、字体大小、行间距 |
| **自定义模板（高级）** | P2 | 支持上传/编辑 Jinja2 模板文件，满足极客用户 |
| **模板收藏** | P2 | 收藏常用模板组合，快速切换 |
| **默认模板设置** | P1 | 为每个角色单独设置默认模板 |

### 技术方案

```
模板系统架构
├── templates/
│   ├── modern/          # 当前默认
│   │   ├── resume.j2
│   │   └── style.css
│   ├── classic/         # 传统两栏式
│   │   ├── resume.j2
│   │   └── style.css
│   ├── minimal/         # 极简单栏
│   │   ├── resume.j2
│   │   └── style.css
│   ├── tech/            # 技术风格（突出项目+GitHub）
│   │   ├── resume.j2
│   │   └── style.css
│   └── foreign/         # 外企英文风格
│       ├── resume.j2
│       └── style.css
├── template_registry.py  # 模板注册、发现、元数据管理
└── theme_config.py       # 主题配置（颜色、字体、间距）
```

### UI 交互流程

```
[简历页面]
    │
    ├─ 顶部控制栏
    │   ├─ 角色选择 [下拉]
    │   ├─ 模板选择 [下拉] ──→ hover 显示缩略图
    │   ├─ 🎨 主题 [按钮] ──→ 弹出配色面板
    │   └─ 生成简历 [主按钮]
    │
    ├─ 中部预览区
    │   └─ 实时渲染所选模板效果（Markdown/HTML）
    │
    └─ 底部操作栏
        ├─ 导出 Markdown
        ├─ 导出 PDF
        └─ ⚙️ 自定义模板 [高级]
```

### 验收标准
- [ ] 内置 ≥4 套模板，覆盖互联网/金融/外企/极简场景
- [ ] 模板切换后预览区 < 2 秒刷新
- [ ] PDF 导出时正确应用所选模板的样式
- [ ] 主题配置（颜色/字体）实时反映在预览和 PDF 中
- [ ] 自定义模板上传后，系统正确解析并可用

## 🎯 今晚验证的重点（Phase 1 准入门槛）

**验证原则：如果以下 3 点有任意一点不成立，Phase 2 暂缓**

1. **"我能用它生成一份可直接投递的简历"**
   - PDF 排版专业、无乱码、信息完整
   - 换角色后简历内容确实发生变化

2. **"岗位匹配结果让我信服"**
   - 粘贴一个你真实想投的岗位，匹配分数与直觉一致
   - Gap 分析指出的短板确实是你的短板

3. **"学习路径推荐对我有行动指导意义"**
   - 推荐的具体资源（课程/书/项目）你愿意去学
   - 不是泛泛而谈的"学 Python"

**如果 3 点全绿 → 进入 Phase 2 体验打磨（含模板配置系统）**
**如果有红灯 → 聚焦修复，不扩展功能**
